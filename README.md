- **🎨 Multi-Theme Neon Color Switcher**: Real-time theme picker supporting 5 custom neon palettes (*Cyber Cyan*, *Neon Magenta*, *Electric Purple*, *Emerald Energy*, and *Sunburst Gold*) with `localStorage` persistence.
- **⚡ Interactive Particle Canvas**: Dynamic background canvas network reacting smoothly to mouse movements and viewport scaling.
- **📊 Live Animated Stats Counters**: Animated metrics counting up to 500+ DSA problems solved, 15+ projects completed, 4+ certifications, and 99% optimization focus.
- **💻 Live Interactive Code Showcase**: Built-in code viewer tab allowing visitors to switch between live code snippets (C++ Graph BFS Algorithm, React Custom Hook, Node.js REST API).
- **📂 Multi-Page Architecture**:
  - `index.html`: Main Engineering Hub & Featured Projects.
  - `about.html`: Detailed Biography, Core Philosophy, and Academic History.
  - `projects.html`: Filterable Project Directory & Systems.
  - `skills.html`: Comprehensive Skill Matrix & Interactive Code Playground.
  - `contact.html`: Communication Portal, Social Links, and FAQ Accordions.
- **🔍 Filterable Projects & Skills**: Dynamic client-side filtering for C++, Web Applications, and Full-Stack systems.
- **📱 Fully Responsive & Accessible**: Built with mobile-first CSS Grid and Flexbox layouts.

## 💻 Local Development Setup

To run this portfolio locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/shantakumarmanan/My-portfolio.git
   cd My-portfolio
   ```

2. **Serve locally**:
   You can serve the directory using any static HTTP server (e.g. Python's built-in HTTP server or Node.js `serve`):
   ```bash
   python -m http.server 8000
   ```
   Or:
   ```bash
   npx serve .
   ```

3. **Open in browser**:
   Navigate to `http://localhost:8000/` in your web browser.
